# ANTO PARKER — Archivo sensible

Portafolio cinematográfico, estático y adaptable a móviles. HTML, CSS y JavaScript sin dependencias de compilación.

## Publicación en GitHub Pages
1. Crea un repositorio público (por ejemplo, `anto-parker`).
2. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `style.css`, `script.js` y `assets/`. No subas solo el ZIP.
3. Ve a **Settings → Pages → Build and deployment**. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. La URL será `https://TU-USUARIO.github.io/anto-parker/` (si el repositorio tiene ese nombre).

## Editar
- Textos y secciones: `index.html`.
- Diseño y adaptación móvil: `style.css`.
- Contenido de las ventanas de proyectos: `script.js`.
- Fotografías originales extraídas de los PDF: `assets/` (formato WebP optimizado).
